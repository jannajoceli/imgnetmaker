ImgNetMaker

ImgNetMaker converts your CSV and/or image folder into network-ready data for visualising image networks with Gephi Lite. It downloads the images when a CSV is provided, pairing each image with its metadata, and adding two fields: a clean image filename and a Base64 data URL. It then builds the network file for you, ready to lay out in Gephi Lite or Gephi. Network building also works on its own, from any CSV or JSON with one row per image.

Yep — zoom through 10,000-images in a snap. 👩🏻‍💻✨❣️ Heads-up: performance depends on your browser’s available memory (RAM).

CSV with image URLs → Images + Data URLs

⬇️ Downloads the images from the web

📨 Input

CSV with at least one column containing an image URL (e.g. image_url). Ensure your file contains additional metadata columns (e.g., id, author, date, …)

⚙️ What ImgNetMaker does

  • Downloads each image (when the server allows it),
  • Derives a stable filename from the last path element in the URL,
  • Converts each image to a base64-encoded data URL.

☑️ Output

  • Enhanced CSV with original columns and
    inm_status — status of image download.
    inm_filename — clean filename used as the image key.
    inm_imgdataurl — the embedded image (data URL).
  • Zip with /images/ folder containing the downloaded images (mirrors inm_filename)
  • Network building: choose the columns that connect the images (e.g. hashtags, accounts) and download a network file for Gephi Lite (images already on the nodes) or a GEXF for Gephi.

Image folder → Data URLs

💻 Uses images already on your computer, nothing is downloaded

📨 Input

Provide an image folder. Optionally, add a metadata CSV with a column holding the image filenames or IDs (e.g. image_filename) to build a network.

⚙️ What ImgNetMaker does

  • All files stay on your computer and are processed locally in your browser. Although the browser will ask to confirm, nothing is uploaded.
  • Leaves your existing folder as-is.
  • Generates a base64-encoded data URL for each image.

☑️ Output

  • A CSV with the columns
    inm_status — status of image conversion,
    inm_filename — your input filename,
    inm_imgdataurl — the embedded image (data URL).
  • Network building: add your metadata CSV and ImgNetMaker matches it to the image filenames for you. Choose the columns that connect the images and download a network file for Gephi Lite (images already on the nodes) or a GEXF for Gephi.

CSV / JSON → Network

🔗 Builds the network from data that already holds the images

📨 Input

A CSV or JSON file with one row per image: a column with the image (a data URL such as inm_imgdataurl from an earlier ImgNetMaker run, or a web link) and metadata columns (e.g. hashtags, account).

⚙️ What ImgNetMaker does

  • Everything stays in your browser; nothing is uploaded.
  • Connects the images through the columns you choose.
  • Splits cells with several values (e.g. #rio #carnaval, or lists in JSON).

☑️ Output

  • Network building: a network file for Gephi Lite (images already on the nodes) or a GEXF for Gephi, as images ↔ values or images linked by shared values.
  • Lay it out in Gephi Lite or Gephi (e.g. ForceAtlas2).

What's next: how to see your image network

In Gephi Lite (file ending in .gephi-lite.json)

  • Drag and drop the file into Gephi Lite. The images are already on the nodes.
  • Spatialise with Layout → ForceAtlas2.
  • To switch images off or on: Appearance → Nodes → Images, column inm_imgdataurl.

In Gephi desktop (file ending in .gexf)

  • Open the file and spatialise with ForceAtlas2.
  • With the Image Preview plugin: in Preview, tick Render Nodes As Images and set Image Path to your images folder (the images folder from the ImgNetMaker ZIP, or your own folder).
